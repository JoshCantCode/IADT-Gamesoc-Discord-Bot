# SocBot - IADT Game Society Community Discord Bot

SocBot is a collaborative project where members of GameSoc can work together to suggest and even make features of the Discord Bot they will all be using!
To suggest, simply either create an [issue](https://github.com/JoshCantCode/IADT-Gamesoc-Discord-Bot/issues), or suggest in in the #suggestions channel in the IADT GameSoc Discord!
This project will be handled by me but other users with an interest in coding can always give this a try!


### Some information
This bot runs on my homelab in a Docker container, and uses [seyfert](https://seyfert.dev) as the Discord bot framework. It runs with pnpm.

### Contributing Guidelines
If you wish to contribute, create a [PR](https://github.com/JoshCantCode/IADT-Gamesoc-Discord-Bot/pulls) and describe the changes you made. They should be easy to understand and able to decipher at a quick glance
If any part isn't easy to understand add a comment where the code is.
No AI slop will be tolerated. If anything is generated with AI it will be instantly denied (and I will also hate you)
